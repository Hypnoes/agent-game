# docs/issues

本目录记录待实施改动的规划。每个文件对应一个 GitHub Issue，文件名形如 `<编号>-<英文短名>.md`。

规划与 Issue 的关系：先在本目录写清背景、设计与验收标准，再据此创建 GitHub Issue 并把编号回填到文件头部；实施在 `issue-<编号>-<短名>` 分支的 worktree 中进行。
